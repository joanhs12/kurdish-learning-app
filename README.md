# Kurdish Learning App

A mobile app for learning the Kurdish language using a clean, modern interface.

Features:
- Daily learning dashboard
- Vocabulary categories
- Common phrases
- Quick pronunciation and grammar practice
- Mini quiz and progress tracking

## Technologies
- React Native
- Expo

## Getting started

1. Install dependencies:
   npm install
2. Start the app:
   npm start
3. Use Expo Go on your device or run an emulator.
