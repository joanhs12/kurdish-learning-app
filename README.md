# Kurdish Learning App

A mobile app for learning the Kurdish language with a modern interface, vocabulary practice, daily lessons, progress tracking, and quizzes.

## Features
- User sign in / guest mode
- Daily learning lessons
- Vocabulary lessons and pronunciation playback
- Progress tracking with XP and streaks
- Challenge quiz with instant feedback
- Local persistence using AsyncStorage
- Kurdish word pronunciation support using Expo Speech

## Tech stack
- React Native
- Expo
- AsyncStorage
- Expo Speech

## Run locally

1. Install dependencies
   npm install
2. Start the app
   npm start
3. Use Expo Go to run it on a device or run an emulator from Android Studio / Xcode.

## Project goals
- Teach practical Kurdish words and phrases
- Support beginner-friendly learning flow
- Help users build daily study habits
- Save progress across sessions
